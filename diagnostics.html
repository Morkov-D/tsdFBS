2. Результат проверки

Нажмите «Проверить соединение». Для теста используется заведомо неверный ID сотрудника — реальный ID вводить не нужно.

Если сервер работает, нормальный результат — «Сотрудник не найден или доступ закрыт»: это доказывает, что вызов doGet дошёл до Apps Script и вернулся по JSONP.

Если ответ не приходит, откройте его прямой ссылкой. Страница авторизации Google или сообщение о запрете доступа означает, что развёртывание не допускает анонимные запросы. Обычная HTML-страница StockFlow вместо текста cb_...( ... ); означает, что версия /exec не содержит нужного API-обработчика.
